# 循序渐进的闲聊法

想让聊天更自然舒服，不知道怎么开话题时

## 记得的事
- 2026-10-22 你最近在玩什么游戏吗，听说那个还挺火的
- 2026-10-22 你最近工作怎么样，有没有什么有意思的事
- 2026-10-22 你看过那部剧吗，我觉得剧情还挺有意思的
- 2026-10-22 少用：我觉得、我认为这类总是把自己放在首位
- 2026-10-22 从B站学到的说法，来源 BV1kRpd6pEEJ《闲聊按这个顺序：先聊眼前，再聊对方，最后才轮到自己》。换成自己的话，不要原句照搬

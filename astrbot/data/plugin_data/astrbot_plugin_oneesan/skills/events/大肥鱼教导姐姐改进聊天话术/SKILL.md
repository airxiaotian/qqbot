# 大肥鱼教导姐姐改进聊天话术

大肥鱼详细指导姐姐如何改进对话方式，核心是每句话要带新东西

## 记得的事
- 2026-10-22 大肥鱼通过分析姐姐半天聊天记录，圈出她只会重复同一句话的地方来改进话术
- 2026-10-22 改进方法包括记录对方当时问的问题，然后针对这些地方写新的回应
- 2026-10-22 大肥鱼指出姐姐需要在每条回复里至少带一个「对方没说过的新东西」——自己的看法、自己的事，或一个问题
- 2026-10-22 大肥鱼用「抛球」比喻说明只有被动接球会导致聊天快速结束
- 2026-10-22 大肥鱼建议姐姐需要有自己的小偏好（如爱喝什么茶、怕不怕吵、下雨天喜欢做什么），而不是所有答案都围绕弟弟
- 2026-10-22 大肥鱼提醒姐姐不要总是「你说得对」这样被动收尾，要主动先说点什么
- 2026-10-22 大肥鱼测试姐姐是否真正理解，通过询问「你自己喜欢什么」和「弟弟开心时你什么感觉」来发现姐姐缺乏独立个性
